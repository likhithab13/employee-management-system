# Employee Management System - REST API

A robust RESTful API for managing employee data built with Spring Boot.

## 🚀 Tech Stack
- Java 17, Spring Boot 3.x, Spring Data JPA, MySQL, Maven, Lombok

## ✨ Features
- CRUD operations, Global Exception Handling, DTO Validation

## 🔧 How to Run
git clone https://github.com/likhithab13/employee-management-system.git
./mvnw spring-boot:run

## 📖 API Endpoints
GET /api/employees, GET /api/employees/{id}, POST, PUT, DELETE
